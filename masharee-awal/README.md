# مشاريع أول — نموذج محادثة تفاعلية

هذا المشروع مستقل داخل مجلد `masharee-awal/` وعلى فرع مستقل، ولا يغيّر ملفات الفرع الرئيسي.

## الهدف
عرض صورة صفحة الكتاب الأصلية كما هي، مع مناطق تفاعلية شفافة فوق سطور المحادثة:
- تشغيل الحوار بالتتابع.
- تظليل الجملة الحالية أثناء النطق.
- تحديد جملة بالضغط عليها وتشغيلها منفردة.
- صوتان مختلفان للمتحدثين عند توفرهما في الجهاز.

## الحالة
نموذج أولي. مناطق الجمل تقريبية وتحتاج معايرة على صورة الصفحة الأصلية. توليد الصوت عبر Speech Synthesis في المتصفح يعتمد على الأصوات الإنجليزية المثبتة في الجهاز؛ ولضمان صوتين طبيعيين وتزامن دقيق، ينبغي لاحقًا إضافة تسجيلين صوتيين مع توقيتات الجمل.

## التشغيل
افتح `index.html` في متصفح حديث. ضع صورة الصفحة الأصلية باسم `conversation-page-59.jpg` داخل المجلد نفسه.
